```markdown
# 🖥️ PC Builder

A sleek and modern web application that helps users explore, compare, and choose pre-built PC configurations for gaming, office, and everyday use.


## 🚀 Features

- 🔍 Browse through a curated list of high-performance PCs
- 📷 Beautiful product image carousel with smooth scrolling
- 🏷️ Labels and highlights for special deals
- 💖 Add PCs to your wishlist
- 📉 Dynamic discount calculation
- 📱 Fully responsive design
- 🌙 Dark mode (optional extension)

---

## 🛠️ Tech Stack

- [Next.js](https://nextjs.org/) – React Framework
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first styling
- [TypeScript](https://www.typescriptlang.org/) – Type-safe development
- [React Icons](https://react-icons.github.io/react-icons/) – Social & UI icons

---
````


### 🧑‍💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/pc-builder.git
cd pc-builder
```


### 2. Install dependencies

```bash
npm install
# or
yarn
```

### 3. Run the development server

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
